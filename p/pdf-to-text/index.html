Give it a list of PDF links and get back one JSON record per file: the text of every page, the full text in one field, and the document's metadata. Metadata covers title, author, subject, keywords, the software that made the file, creation and modification dates, PDF version, page count, and file size.

It reads the text layer with pdf.js, the PDF engine used in Firefox. It checks each site's robots.txt first, waits out any Crawl-delay, and stops downloading if the file is not really a PDF.

Good for feeding reports, papers, forms or manuals into a search index or a language model, or for checking what a batch of PDFs contains without opening them.

Options: maxItems to cap cost, maxPagesPerPdf, a file size limit, and switches to drop the per-page or full-text fields.

Limits: there is no OCR, so scanned PDFs return empty text with has_text set to false (they are still billed). Public files only, no logins or password-protected PDFs. Tables and multi-column layouts can come out with lines interleaved. Files over 100 MB are skipped.
