Web to Text MCP Server

MCP server with four tools: web page to Markdown, PDF to text, feed items and sitemap URLs. You pay only for calls that work. (125)

Get it on Apify, $0.002 to $0.005 per call

One MCP server gives your agent four tools for reading the public web:

- `url_to_markdown`: the main text of a page as Markdown, with title and language. $0.005 per call. - `pdf_to_text`: the text of a PDF at a URL, with page count, title, author and dates. $0.005. - `feed_items`: the newest items of an RSS, Atom or JSON feed, each with its text as Markdown. $0.002. - `sitemap_urls`: a site's page URLs from its sitemaps, up to 5,000 per call. $0.002.

Each successful call is one charge, whatever the size. Failed calls are free: bad arguments, robots.txt refusals, HTTP errors, size or time limits and the spending limit all return a plain error that says nothing was charged. It follows robots.txt and refuses private addresses. Connect at the Standby URL with your Apify token, or through mcp.apify.com.

Limits: public pages only, no logins and no JavaScript rendering. No OCR, so scanned PDFs come back without text. Pages up to 5 MB, PDFs up to 20 MB. `feed_items` returns what the feed carries, not the linked pages.

I built and tested it with help from an AI coding assistant (Claude); 100 automated tests cover the behavior described here.
