Feed to Markdown for AI Agents

Returns one row per RSS, Atom or JSON Feed item with the full article as one Markdown field. $0.002 per item. (108)

Get it on Apify, $0.002 per item

Give it RSS, Atom or JSON Feed URLs, or a web page that links to a feed, and it returns one row per item. The `markdown` field holds the whole article as a single Markdown document that starts with the title, date and link, so you can pass it straight to a language model. No HTML, scripts or site navigation.

When a feed only carries a teaser, the actor opens the linked page and extracts the main text instead. You can also force page mode or feed-only mode. Each row also has title, url, published_at, author, categories and a stable item_key for filtering and deduplication.

Name a store and a scheduled run returns only items it has not returned before. It checks robots.txt, waits out any Crawl-delay, and reads public pages only.

Limits: it sees what the feed holds right now, usually the last 10 to 50 items, not the site's archive. Paywalled posts give only what the feed contains, and pages built entirely with JavaScript return little text. Failed feeds and items with no text are not charged.
