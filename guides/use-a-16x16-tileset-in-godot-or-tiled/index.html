How to Use a 16x16 Pixel Tileset in Godot or Tiled, With Autotiling

Import a 16x16 tile sheet, keep the pixels sharp, paint floors and walls with terrain autotiling in Godot 4 or Tiled, and layer props on top.

A tileset is one PNG with many small square pictures on a grid, plus some data that says which tile goes where. For a top-down game at 16x16, the work is in three places: getting the sheet into the engine without blurring it, painting large areas quickly, and keeping walls and water on their own layers so they overlap the floor cleanly. Here is how to do each in Godot 4 and in Tiled, with any 16x16 sheet.

Step 1: Keep the pixels sharp

Pixel art blurs when the engine scales it with a smooth filter. Fix that before anything else.

  • Godot 4: Project Settings, Rendering, Textures, set Default Texture Filter to Nearest. Then scale the whole viewport by a whole number (2x, 3x, 4x) with Display, Window, Stretch mode canvas_items and a base size that divides evenly into your screen.
  • Tiled: View, Zoom, use whole number steps (200%, 300%). Tiled never filters, so the map editor is already sharp.
  • Any engine: never scale by 1.5x or 2.7x. Pick 2x, 3x or 4x.

Step 2: Import the sheet

Godot 4

  1. Drop tileset.png into the project. In the Import dock make sure Filter is off (or rely on the project default from step 1).
  2. Add a TileMapLayer node (or a TileMap in 4.2 and earlier). In the inspector create a new TileSet, set Tile Size to 16 x 16.
  3. In the TileSet panel at the bottom, add an Atlas, pick tileset.png, and click "Yes" when it offers to create tiles automatically. Delete the transparent slots you do not need.

Tiled

  1. File, New, New Tileset. Choose "Based on Tileset Image", pick the PNG, tile width and height 16, margin and spacing 0.
  2. Save it as a .tsx next to the PNG, then add it to a map with 16 x 16 tiles.

If the pack already ships a .tsx, open that instead and skip the setup.

Step 3: Autotile floors, water and walls

Painting walls one tile at a time means choosing the right corner piece every time. Autotiling (terrains in Godot, Wang sets in Tiled) does the choosing for you: you paint "wall" and the engine picks the tile whose edges match its neighbours.

A full set in the common 47-tile "blob" layout covers every arrangement of 8 neighbours, including inner corners. The rule behind it: each neighbour is a bit (N 1, NE 2, E 4, SE 8, S 16, SW 32, W 64, NW 128), a corner bit only counts when both sides next to it are set, and a lookup table turns the resulting mask into a tile index.

  • Godot 4: in the TileSet panel open Terrain Sets, add a set with mode "Match corners and sides", add a terrain (for example Wall), then paint the terrain peering bits on each of the 47 tiles. Once set up, choose the terrain in the TileMap toolbar and paint. The peering bit painting is the slow part: 47 tiles times 8 bits.
  • Tiled: select the tileset, open the Wang Sets view, create a set of type Mixed, assign colours to each tile's corners and edges, then use the Terrain Brush on the map. Same work, same payoff.
  • Your own engine: keep the 256-entry lookup table in code and compute the mask per cell at load time.

Step 4: Layer it

Put each kind of thing on its own layer: floor at the bottom, then water, moss or other ground features, then walls, then props. Autotile tiles are transparent where the floor should show through, so a wall or pool only looks right over a floor layer. Keep one terrain per layer; most packs have no tiles for two terrains meeting inside one cell.

Props (doors, chests, torches, stairs) go on the top layer. In Godot, give that layer a higher Z index or put it in a separate TileMapLayer so a character can walk behind tall props if you add any.

Step 5: Make the floor less repetitive

If the pack gives several floor variants with matching edges, fill the layer with the plain tile and then scatter the others at random. In Godot use Scatter in the TileMap paint tool; in Tiled use the Stamp Brush with Random mode on a selection of floor tiles.

FAQ

Does the Tiled file work in Godot?

Godot 4 does not open .tmx directly, but the free "YATI" importer add-on does, including Wang sets as terrains. Or build the TileSet in Godot from tileset.png using the lookup table in tileset.json.

Can I use it in Unity, GameMaker or RPG Maker?

The PNG works anywhere that reads a 16x16 grid. Unity's Tilemap has Rule Tiles for autotiling; GameMaker has its own autotile editor with a 47-tile mode; RPG Maker expects its own autotile layout, so the blob set needs rearranging there.

How do I scale the sheet up for a 48 pixel tile game?

Do not scale the PNG. Keep the tiles at 16x16 and scale the camera or canvas by 3x with nearest-neighbour filtering. The result is the same on screen and the files stay small.
