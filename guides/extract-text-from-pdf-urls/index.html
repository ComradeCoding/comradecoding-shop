How to Extract Text and Metadata From PDF Links in Bulk

Get the text of every page and the title, author, dates and page count from a list of PDF URLs, with free command line tools or in one batch run.

You have a list of PDF links: reports, papers, manuals, forms, a public document archive. You want the text inside them for a search index or a language model, and the metadata (title, author, creation date, page count) in a table. Opening each file by hand is not an option past a dozen or so.

Here is the free way to do it, what goes wrong, and a faster option for long lists.

Step 1: Collect the links

Put one PDF URL per line in a text file, urls.txt. Make sure each link points at the PDF file itself, not at a web page that shows or links to it. A quick test: open the link and check that the browser shows the PDF viewer, or that the address ends in the file.

Step 2: Download the files

With wget or curl, politely, with a pause between requests:

wget --wait=1 --random-wait -i urls.txt -P pdfs/

Some sites ask for a longer delay in their robots.txt Crawl-delay line. Respect it.

Step 3: Extract text and metadata

Poppler's command line tools are free and fast. pdftotext writes the text and pdfinfo prints the metadata:

for f in pdfs/*.pdf; do
  pdftotext -layout "$f" "${f%.pdf}.txt"
  pdfinfo "$f" > "${f%.pdf}.info.txt"
done

pdfinfo shows fields such as Title, Author, Creator, Producer, CreationDate, ModDate, Pages and PDF version. In Python, pypdf gives you the same data per page if you want JSON instead of text files.

Step 4: Check what you got

  • Empty text. If a file returns no text, it is probably a scanned document: the pages are images. You need OCR for those, for example Tesseract or ocrmypdf, which adds a text layer you can then extract.
  • Missing metadata. Many PDFs leave title and author blank, especially ones made by scanners or LaTeX. That is normal.
  • Odd order. Text comes out in the order it is stored in the file. For single column documents that is reading order. Multi column layouts and tables can come out with columns mixed together.
  • Not a PDF. If the server returned an HTML login or error page, the tools will fail on it. Check the first bytes or the file type.
  • Your rights. The text includes whatever is printed in the document, names and contact details included. Make sure you may use it.

FAQ

Can I extract tables from PDFs this way?

Not as tables. Both pdftotext and the actor return text in stored order, so cells may land on separate lines. For real tables, use a table extraction tool such as Camelot or Tabula on the downloaded files.

How do I tell which PDFs are scanned?

With pdftotext, look for empty output files. With the actor, filter rows where has_text is false.

Does it work on PDFs behind a login?

No. Both methods above assume public links. Download private files yourself and process them locally.

What about web pages, not PDFs?

Use a web page converter instead; see how to convert a web page to Markdown.
