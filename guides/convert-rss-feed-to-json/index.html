How to Convert an RSS or Atom Feed to JSON

Turn RSS 2.0, RSS 1.0, Atom or JSON Feed items into flat JSON rows with clean dates, with a few lines of Python or a scheduled run that returns only new items.

RSS and Atom feeds are still the simplest way to follow blogs, news sites, release notes and podcasts. They are XML, though, and every format names its fields differently: RSS has pubDate and guid, Atom has updated and id, and dates come in several styles. If you want feed items in a database, a spreadsheet, or a language model's context, the first job is to turn them into one consistent JSON shape.

Step 1: Find the feed URL

  • Look for an RSS icon or a "feed" link on the site.
  • Try common paths: /feed/, /feed.xml, /rss.xml, /atom.xml, /index.xml.
  • View the page source and search for application/rss+xml or application/atom+xml. The <link rel="alternate"> tag that contains it holds the feed URL.

Step 2: Convert with a few lines of Python

The free feedparser library reads RSS, Atom and other variants into one Python structure. Install it with pip install feedparser, then:

import json, time, feedparser

feed = feedparser.parse("https://blog.rust-lang.org/feed.xml")
rows = []
for e in feed.entries:
    t = e.get("published_parsed") or e.get("updated_parsed")
    rows.append({
        "title": e.get("title"),
        "url": e.get("link"),
        "id": e.get("id"),
        "author": e.get("author"),
        "published_at": time.strftime("%Y-%m-%dT%H:%M:%SZ", t) if t else None,
        "summary": e.get("summary"),
    })
print(json.dumps(rows, indent=2))

feedparser normalises dates to UTC in the *_parsed fields, which saves a lot of date handling.

Step 3: Clean up the fields

  • Summaries are often HTML. Strip tags if you want plain text.
  • Not every item has a date. Keep those items, but do not rely on sorting by date.
  • Links can carry tracking parameters such as utm_source. Remove them before you compare links.
  • Podcast audio is in the item's enclosure (e.enclosures in feedparser), with a URL, type and length.
  • Feeds only hold recent items. Most keep somewhere between 10 and 50 entries. If you need history, poll on a schedule and store what you see.

Step 4: Keep only new items

To watch feeds over time, save a key for every item you have stored (the id, else the link, else the title and date) and skip items whose key you already have. Run the script on a schedule with cron or Task Scheduler.

FAQ

What is the difference between RSS and Atom?

Both are XML feed formats. Atom is a later standard with stricter rules on dates and ids. For converting to JSON the difference is mostly field names, which a parser or the actor maps for you.

Can I get older posts than the feed shows?

Not from the feed. It only contains recent items. Start polling now and keep what you collect, or list older pages from the site's sitemap; see how to get every URL from a sitemap.

How do I get the full article text?

Fetch each item's link and extract the main content. The actor's fetchFullText does this, or see how to convert a web page to Markdown.

Does this work for podcast feeds?

Yes. Podcast feeds are RSS, and the audio file is the item's enclosure.
