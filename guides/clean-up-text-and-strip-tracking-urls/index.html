Step 2: Strip HTML and decode entities

import html, re
from bs4 import BeautifulSoup

def strip_html(s):
    if re.search(r"<(p|br|div|a|li|span|h[1-6])\b", s):
        return BeautifulSoup(s, "html.parser").get_text("\n")
    return html.unescape(s)

The check for a real tag matters: plain text such as if a<b and c>d or List<String> is not HTML, and running it through a parser throws words away.

Step 3: Normalise Unicode and whitespace

import unicodedata

def tidy(s):
    s = unicodedata.normalize("NFC", s)
    s = re.sub(r"[​‌﻿­]", "", s)      # zero width space, BOM, soft hyphen
    s = "\n".join(re.sub(r"[ \t ]+", " ", line).strip() for line in s.splitlines())
    return re.sub(r"\n{3,}", "\n\n", s).strip()

Use NFKC instead of NFC if you also want ligatures (ﬁ) and full-width letters (ＡＢＣ) turned into plain ones, which helps search and matching.

Step 4: Remove tracking parameters from links

from urllib.parse import urlsplit, urlunsplit, parse_qsl, urlencode

TRACKERS = {"fbclid", "gclid", "msclkid", "mc_eid", "mc_cid", "igshid", "yclid", "ttclid", "_hsenc", "_hsmi", "mkt_tok"}

def clean_url(u):
    parts = urlsplit(u)
    q = [(k, v) for k, v in parse_qsl(parts.query, keep_blank_values=True)
         if not (k.lower().startswith("utm_") or k.lower() in TRACKERS)]
    return urlunsplit(parts._replace(query=urlencode(q)))

text = re.sub(r"https?://[^\s<>\"')]+", lambda m: clean_url(m.group(0)), text)

The one-pass route for lists of texts

Each row has the cleaned text plus counts of what changed: mojibake_fixed, params_removed, urls_changed and whether html_stripped. Send an id with each text and it is copied to the output row, so you can join results back to your records. It makes no network requests; it only reads the text you send.

Options:

  • htmlMode: auto strips tags only when the text has a real HTML tag; strip always treats it as HTML; keep leaves tags alone.
  • fixMojibake: on by default. Turn off for text you know is correct.
  • unicodeForm: NFC (default), NFKC, NFD, NFKD or none.
  • whitespace: lines (default), collapse to one line, or keep.
  • cleanUrls: removes utm_ parameters and 30 named trackers such as fbclid, gclid and msclkid.
  • maxItems: stop after this many rows.

FAQ

Why did my line breaks disappear?

The text was treated as HTML, where line breaks come from tags, not newlines. Use htmlMode: keep for plain text that happens to contain something like <b>.

Will it change text that is already correct?

Only by the steps you leave on: whitespace, Unicode normalisation, invisible characters and tracking parameters. For the lightest touch set fixMojibake: false, whitespace: keep and unicodeForm: none.
